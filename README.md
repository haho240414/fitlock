# 핏락 (가칭)

**운동을 해야 열리는 안드로이드 잠금화면.** 화면을 켜면 "스쿼트 10개 하면 열려요"가 먼저 뜨고,
폰을 가슴에 대고 스쿼트를 하면(또는 폰을 세워 두고 카메라 앞에서 운동하면) 횟수를 세서 열어 준다.
캐시워크처럼 잠금화면에서 오늘 포인트·연속 기록·레벨이 보이고, 오늘의 미션·상점으로 계속 쓰게 만든다.

> ⚠️ **운동 습관용 잠금이지 보안 잠금이 아니다.** 폰의 PIN·지문 잠금은 그 뒤에 그대로 있고(운동을 다 하면 시스템 잠금 해제 화면이 뜬다),
> '급할 때 그냥 열기'·긴급 전화·홈 버튼으로 언제든 나갈 수 있다. 전화가 오면 바로 비킨다. 센서·카메라를 못 쓰면 그냥 열린다.

- 안드로이드 8.0 이상 전용 (iOS 는 다른 앱이 잠금화면 위에 화면을 띄울 수 없다)
- [핸즈프리 PT](https://github.com/haho240414/handsfree-pt)의 변주: 카메라 운동 인식 엔진을 그대로 가져와 '카메라 모드'에 쓴다
- 서버 없음 · 광고 없음 · 기록은 이 폰에만 · 카메라 영상과 위치는 밖으로 나가지 않는다

1. 폰에서 위 링크 → 받기 → 설치 ("출처를 알 수 없는 앱" 허용, Play 프로텍트 경고는 '무시하고 설치')
2. 앱 → **잠금 켜기** → 안내대로 권한을 켠다
   - **다른 앱 위에 표시** (꼭 필요): 화면이 꺼질 때 잠금화면 위에 운동 화면을 띄우는 데 쓴다
     - 안드로이드 15+ 에선 직접 받은 앱은 이 스위치가 회색으로 막혀 있다 → **설정 → 애플리케이션 → 핏락 → 오른쪽 위 ⋮ → 제한된 설정 허용** 후 다시 켠다
   - 알림(오늘 기록·상태를 상단에), 배터리 제한 없음(삼성 등이 절전으로 멈추지 않게), 카메라(카메라 모드만), 위치 '항상 허용'(장소 조건만)
3. 화면을 껐다 켜 보면 운동 화면이 먼저 뜬다

## 기능

- **화면 켤 때 운동 잠금**: 화면이 꺼지는 순간 운동 화면을 미리 띄워 둔다 → 켜면 바로 보인다 (시스템 잠금 위에 '보이기'만, 화면을 스스로 켜진 않음)
  - 다 하면 `+15P` 동전 애니메이션 → 시스템 잠금 해제(PIN·지문) 화면 → 폰 사용
  - **한 번 하면 자유**: 매번 / 15분 / 30분 / 1시간(기본) / 2시간 / 3시간 / 하루 한 번. 홈 화면에서 '자유 시간 끝내고 다시 잠그기'
- **세는 방법 두 가지**
  - **📱 폰 들고(기본)**: 폰을 두 손으로 가슴에 대고 스쿼트·런지 → 움직임 센서로 센다. 깊이 막대(이만큼 앉으면 1회), 덜 앉으면 "조금 더 깊게"
  - **📷 세워 두고**: 폰을 2~3m 앞에 세우고 카메라로 — 핸즈프리 PT 엔진으로 고른 운동만 1회째부터 센다(스쿼트·푸시업·런지·점핑잭·버피·마운틴 클라이머·윗몸일으키기·힙 브릿지·사이드 런지·숄더 프레스·덤벨 컬·하이니). 잠금 화면에서 바로 바꿀 수 있고 센 만큼 이어진다
  - 숫자 음성(무음·진동 모드면 자동으로 끔)·셀 때마다 진동
- **못 할 때**
  - 네이티브 버튼 줄(웹 화면이 멈춰도 눌림): **🚨 긴급 전화**(잠금 상태에서도 되는 긴급 통화 화면) · **급할 때 그냥 열기**
  - 하루 무료 건너뛰기 N번(기본 3) — 넘어도 열리긴 하고 기록에만 '건너뜀'. 건너뛰면 최소 10분은 다시 안 잠김
  - **시간대**: 요일·시간을 여러 개(밤을 넘겨도 됨). 그 밖엔 안 잠근다
  - **장소**: '이곳에서만 잠금'(예: 집) 또는 '이곳에선 잠금 안 함'(예: 회사). 위치(반경 100~500m)나 와이파이 이름으로. **위치를 모르면 잠그지 않는다**
  - 전화가 울리거나 통화 중(메신저 통화 포함)이면 잠그지 않고, 잠금 중이면 바로 비킨다(통화 뒤 10분은 안 잠김)
  - 센서 값이 2.5초 안 오거나 카메라를 못 쓰면 그냥 열어 준다. 웹 화면이 12초 안에 준비되지 않아도 그냥 열린다
- **캐시워크 느낌**
  - 포인트: 1회 1P · 운동으로 잠금 해제 +5P · 그날 첫 운동(출석) +10P · 연속 3·7·14·30일 보너스
  - 연속 기록(이번 주 점 7개), 레벨(누적 포인트 0·100·300·600…, '새싹'→'핏락 신')
  - 오늘의 미션 3개(날마다 바뀜: 30·60·100개, 잠금 3·5번, 아침 9시 전, 건너뛰지 않고, 카메라 모드 …) → '받기'
  - 상점: 건너뛰기권 · 연속 기록 보호권 · 잠금화면 테마(바다·노을·숲). **포인트는 앱 안에서만** (현금·기프티콘 아님)
  - 기록: 지금까지 개수·잠금 해제·운동한 날·최장 연속, 2주 그래프, 최근 기록
- 상단 알림: 오늘 포인트·연속 기록 + 지금 상태(잠금 대기·자유 시간 몇 시까지·쉬는 시간대·장소 밖)
- 백업 파일 저장·불러오기, 센서 기록 보내기(튜닝용)

## 폰 들고 세기 (새로 만든 것) — 아직 실제 폰으로 맞추는 중

카메라는 폰을 2~3m 떨어진 곳에 세워야 해서 잠금을 풀 때마다 쓰기엔 번거롭다. 그래서 기본은 폰을 가슴에 대고 하는 스쿼트를
가속도·회전 센서로 센다 (`app/js/motion/rep-sensor.js`).

- 중력 방향으로 본 가속도를 두 번 '새는 적분'(오래된 값은 잊음)해서 폰 높이 변화를 어림 → 위 → 아래(13cm 이상) → 위면 1회.
  폰을 어떻게 들든(세로·가로·눕혀서) 같다
- 동작 모양도 본다: 1초 안에 아래로 빨라졌다가, 일어선 끝에서 1초 안에 멈춰 서야 1회 → 앉은 채 가만히 있기·폰 들어 올리기는 안 셈
- 가만히 서 있다 시작한 첫 회는 높이 어림이 절반쯤으로 작게 나와서 따로 본다. 폰을 크게 돌리는 중(만지작)엔 안 셈
- 처음 시도했다가 버린 방식(기록): 반 동작마다 속도를 0 으로 맞추는 그냥 적분 — 센서 치우침이 조금만 있어도 오차가 회마다 쌓였다.
  움직이는 중에도 치우침을 고치면 동작 자체를 빨아들여 '앉아서 가만히'가 1회로 세졌다
- **물리 모델로 만든 가짜 센서 값**(`app/js/motion/synth.js`: 손떨림·센서 잡음·치우침·폰 융합 지연·표본 빠짐)으로
  17가지 상황 × 폰 드는 방향·조건 8가지를 채점했다 (`node tools/motion-eval.mjs`, 6 seed = 816번):

  | 상황 | 결과 |
  |---|---|
  | 보통·빠른·깊은 스쿼트, 런지, 폰 들어 올리고 바로 하기 | 거의 모두 정확 (10/10) |
  | 느린 스쿼트(한 번 4~5초) | 대부분 정확, 잡음 큰 폰·중력 뺀 값 없는 폰에서 가끔 1~2개 놓침 |
  | 반 스쿼트(가슴 19~24cm) | 가끔 첫 회를 놓침 (9/10) |
  | 까딱(7~10cm) | 대부분 안 셈, 가끔 1~3개 셈 |
  | 가만히 들고 1분·만지작·앉아서 가만히·엘리베이터·뛰기 | 0회 |
  | 걷기 1분·버스 1분 | 대부분 0, 가끔 1회 |

- 실제 폰 기록을 받으면: 설정 → **센서 기록 보내기**(최근 5번, 움직임 값만) → `node tools/motion-replay.mjs <파일> --trace` 로
  그대로 재현 → 맞춘 뒤 `--save 이름`으로 `test/fixtures/motion/`에 넣으면 단위 테스트가 정답을 지킨다

## 안드로이드에서 어떻게 동작하나

- 잠금을 켜면 **포그라운드 서비스**(`LockService`, 종류 specialUse, 상단 알림)가 화면 꺼짐·켜짐 방송을 듣는다(매니페스트로는 못 받는 방송)
- 화면이 꺼질 때 `LockGate` 로 정한다: 꺼 둠 → 통화 중 → 자유 시간 → 시간대 밖 → 장소(모르면 안 잠금) → 잠금
- 잠글 때면 `LockActivity`(잠금화면 위에 보이는 화면, `showWhenLocked`)를 띄운다. 백그라운드에서 화면을 여는 건
  안드로이드 10+ 에서 **'다른 앱 위에 표시' 권한이 있을 때만** 된다 ([공식 문서](https://developer.android.com/guide/components/activities/background-starts))
- 운동 화면은 같은 웹앱의 `lock.html` (Capacitor, 시작 경로만 바꾼 설정). 아래 버튼 줄은 네이티브라 웹이 멈춰도 눌린다
- 다 하면 `requestDismissKeyguard` 로 시스템 잠금 해제 화면을 띄우고 닫힌다 (핏락이 PIN 을 대신 풀지 않는다)
- 카메라·센서는 서비스에서 절대 켜지 않는다. 운동 화면이 '보일 때'(화면 켜짐 + 맨 앞)만 웹이 켜고, 숨겨지면 끈다
- 재부팅·업데이트 뒤엔 `BootReceiver` 가 서비스를 다시 켠다

## 자동 점검 (GitHub Actions)

`main` 이나 작업 브랜치에 올리면: 웹 단위 테스트 + 센서 세기 채점 → APK 빌드 + 잠금 판단 JVM 단위 테스트 →
**안드로이드 에뮬레이터 2대(안드로이드 14 = API 34, 안드로이드 16 = API 36)에서 실제 잠금 흐름**(`.github/scripts/lock-smoke.mjs`) → (`main` 만) Releases 갱신.

에뮬레이터 점검: PIN 걸기 → 화면 끄기·켜기 → 잠금화면 위에 운동 화면 → 그 화면에 센서 값이 들어오나 → 가짜 스쿼트(같은 코드 길로 주입) →
열림 → 시스템 PIN 화면 → PIN 으로 풀기 → 포인트 → '급할 때 그냥 열기'(네이티브 버튼을 실제로 누름) → 전화 걸기(에뮬레이터 가짜 전화)로 비키기 →
카메라 모드(가상 카메라·CPU)·화면 끄면 카메라 꺼짐 → 긴급 전화 버튼

- 2026-10-02 v0.1.5: 두 에뮬레이터 모두 필수·참고 항목 전부 통과 (잠금 화면에 실제 센서 값 240~350개, 카메라 960×1280 에서 CPU 로 29~42장 분석, 앱 죽음 0건)
- 안드로이드 16 에서 처음엔 잠금 화면이 0.3초 만에 닫혔다: 화면이 꺼지며 멈출 때 시스템이 '사용자가 떠남'(onUserLeaveHint)을 보내서
  '홈 버튼 = 건너뛰기'가 스스로 닫은 것. 띄울 때 `FLAG_ACTIVITY_NO_USER_ACTION` + 홈 판정은 화면이 켜져 1.5초 넘게 보인 뒤에만으로 고침
- **실제 폰에서는 아직 확인하지 않았다** (삼성 절전·지문 해제 순서·실제 센서 값은 폰에서만 알 수 있다)
